# Lean formalization route for *A Projective Approach to Non-Dividing Sets*

This roadmap is designed for a token-efficient Codex agent. It distinguishes the manuscript’s own arguments—which must be formalized—from exact external results that may be trusted.

## 1. Formal target

Define, for a finite set `A` of positive natural numbers,

```lean
NonDividing A : Prop
```

to mean that for every `a ∈ A` and every nonempty finite `S ⊆ A.erase a`, `a` does not divide `∑ s in S, s`.

Define `F N` as the maximum cardinality of a non-dividing subset of `Finset.Icc 1 N`. Prove that the maximum exists and is attained.

Export at least these theorem forms (names may differ):

```lean
theorem main_upper_eps :
  ∀ ε : ℝ, 0 < ε → ∃ N₀ : ℕ, ∀ N ≥ N₀,
    (F N : ℝ) ≤ Real.rpow N ((1 : ℝ) / 5 + ε)

theorem main_lower_eps :
  ∀ ε : ℝ, 0 < ε → ∃ N₀ : ℕ, ∀ N ≥ N₀,
    Real.rpow N ((1 : ℝ) / 5 - ε) ≤ F N

theorem main_log_limit :
  Tendsto (fun N : ℕ => Real.log (F N) / Real.log N)
    atTop (𝓝 ((1 : ℝ) / 5))
```

The exact casts and domain restrictions may be adjusted to idiomatic mathlib, but the mathematical content must remain equivalent. It is acceptable to prove the epsilon statements first and derive the limit only after eventual positivity is established.

For the central projective theorem, avoid an informal `o(1)` statement. Use:

```lean
∀ ε > 0, ∃ n₀, ∀ ...,
  n₀ ≤ V.card → V.card ≤ Real.rpow B.card (σ d + ε)
```

with fixed `d` and polynomial-box exponent `β`, and uniformity in the shell functional and shell parameter built into the quantifier order.

## 2. Recommended representation choices

Use these unless the existing repository already has superior compatible abstractions.

### Finite vectors and boxes

- Integer vectors: `Fin d → ℤ`.
- Real vectors: `EuclideanSpace ℝ (Fin d)` or `Fin d → ℝ`, choosing whichever makes convex and measure APIs easier.
- A symmetric coordinate box is encoded by radii `M : Fin d → ℕ` with carrier
  `|x i| ≤ M i`.
- Prove its cardinality formula once and reuse it.
- Keep a coercion/embedding from the integer box to the real box.

### Integer linear functionals

Represent `λ : (Fin d → ℤ) →+ ℤ`, preferably generated by an integer coefficient vector. Define its real extension and prove compatibility with coercions. Define

```lean
shellNonDividing (λ) (X : ℕ) (V : Finset (Fin d → ℤ)) : Prop
```

including both `X ≤ λ v ≤ 2*X` and the forbidden subset-sum divisibility property.

### Projective normalization

For shell points define

```lean
π v = (λ v : ℝ)⁻¹ • (v : Fin d → ℝ)
```

and prove `λℝ (π v) = 1`. Package the affine hyperplane `Hλ` and its induced finite-dimensional Euclidean structure.

### Homogeneous GAPs

Create a structure with:

- displayed dimension `e`;
- step vectors `q : Fin e → (Fin d → ℤ)`;
- positive integer radii `N : Fin e → ℕ`;
- coefficient box;
- evaluation map;
- carrier;
- dilation `tP` using floor;
- properness as injectivity on the displayed coefficient box;
- step lattice and real step span;
- **displayed dimension and real rank as separate notions**.

Prove coefficient identification only for a proper GAP. Never treat it as an ambient homomorphism outside the GAP. Prove the transported shell-functional lemma exactly as in the manuscript.

### Asymptotics

Use explicit `∀ ε, ∃ N₀, ...` formulations for all “sufficiently large”, `O`, and `o` assertions whenever possible. Introduce small helper predicates only when they reduce repetition. Avoid building a large custom asymptotic framework before the elementary modules compile.

## 4. Exact external-input whitelist

Search mathlib first. Only when the needed result is absent may it be declared as a trusted external theorem interface. Each interface must be no stronger than the cited result and must include all hypotheses.

### E1. Homogeneous subset-sum structure theorem

Source: Conlon–Fox–Pham, in the higher-dimensional form recorded by Pham–Zakharov, Corollary 5.

The interface may assert exactly the manuscript’s `thm:cfp-structure`: for fixed ambient dimension and `β > 1`, sufficiently large finite `C` in a polynomial-size axis-parallel box has `Ĉ`, a bounded-dimensional symmetric homogeneous GAP `P(C)` containing `Ĉ ∪ {0}`, a core `C₀` of size at most `s(C)=|C|/(log |C|)^2`, a translate `q`, the inclusion

```text
q + c*s(C)*P(C) ⊆ Σ(C₀),
```

and properness of `c*s(C)*P(C)`.

Do not include preprocessing, irreducibility, the progression-comparison lemma, or any later consequence in this external interface.

### E2. Discrete John lemma

Source: Pham–Zakharov, Lemma 7.

Trust only the proper symmetric rank-`r` GAP sandwich/cardinality result in the appropriate lattice. Derive the manuscript’s `convex-lattice-john` lemma from it, plus E5 if a full-rank lattice-point/volume estimate is needed.

### E3. Zonotope rounding lemma

Source: Conlon–Fox–Pham as used in Pham–Zakharov, Lemma 13 and equation (15).

Trust the coordinate-box rounding statement with its explicit coordinate error and sign. Prove `one-sided-filling` from it and E1.

### E4. Set-valued convex-density lemma

Source: Pham–Zakharov, Lemma 1.

Trust only the published theorem for a **set of distinct points** in convex position. The indexed/weighted version in the manuscript is not external and must be derived by perturbation and compactness.

### E5. Standard convex/lattice geometry not already in mathlib

Only exact general-purpose versions of the following may be trusted if absent from mathlib:

- Blaschke selection for uniformly bounded compact convex bodies;
- continuity of convex-body volume under Hausdorff convergence;
- Rogers–Shephard inequality;
- Minkowski’s second theorem and/or the precise successive-minima lattice-point bound used to obtain `|K ∩ ℤ^d| ≪_d vol(K)` when the last successive minimum is at most one;
- routine finite-dimensional measure normalization facts, only if mathlib lacks them.

Prefer proving the manuscript’s perspective-cone volume formula from mathlib measure theory. If that becomes the sole blocker, an exact general cone-volume/Jacobian theorem may be added to E5, but not the cap-lifting lemma itself.

### Forbidden external interfaces

Never trust or axiomatize:

- translation lemma;
- lower-bound construction;
- functional transport;
- progression comparison;
- unshifted preprocessing;
- slab count/exclusion;
- one-sided filling;
- GAP containment;
- lattice section bound;
- full-rank/index lemma;
- projective span;
- projective duality;
- robust zonotope;
- projective convexity;
- weighted indexed density;
- cap lifting;
- numerology;
- projective theorem;
- main theorem.

These are the contribution/proof chain of the manuscript and must be kernel-checked from earlier results.

## 5. Dependency graph and implementation order

### Phase A — Foundations and lower bound

1. `Basic.lean`
   - `NonDividing`, `NonAveraging`, subset-sum notation.
   - monotonicity under subsets.
   - `F N`, finiteness, maximum/attainment lemmas.
2. `LowerBound.lean`
   - translation lemma.
   - translated parabola construction `b_i = (m^3+1)i+i^2`.
   - prove non-averaging by the modulo argument and the identity
     `∑ (i-j)^2 = 0`.
   - prove containment in `[2m^5]`.
   - derive the asymptotic lower epsilon bound for `F`.

Compile and audit this phase before introducing convex geometry.

### Phase B — Boxes, GAPs, shells, and exact external APIs

3. `Box.lean`, `GAP.lean`, `Shell.lean`
   - coordinate boxes and cardinality estimates;
   - homogeneous GAP operations and proper coefficient identification;
   - shell non-divisibility and projective normalization;
   - functional transport, preserving all forbidden divisibility relations exactly.
4. Implement E1–E5 interfaces in `External/` after local mathlib searches.
5. Add tests that a proper homogeneous coefficient identification preserves actual subset sums and non-divisibility.

### Phase C — Structural preprocessing

6. Prove `progression-comparison` from E1 and E2.
7. Formalize structural packages as fixed data chosen before the iteration. Ensure constants are uniform over the finite dimension range; do not make post-hoc choices.
8. Prove `unshifted-preprocessing`:
   - accepted moves and stopping conditions;
   - dimension bookkeeping;
   - product estimate;
   - bound on total upward dimension change;
   - eligibility and cardinality cutoffs never trigger;
   - the three output box estimates.

The proof is easier if all implicit constants become named positive constants and all “large enough” requirements are accumulated into one maximum threshold.

### Phase D — Geometric–arithmetic lemmas

9. `convex-lattice-john` from E2/E5.
10. `slab-count`, including the full-rank Fubini volume estimate.
11. `slab-exclusion`, preserving the `r < d` and `r = d` cases.
12. `one-sided-filling` from E1/E3:
    - prove the step vectors form a lattice basis under dimension/rank hypotheses;
    - track the sign of the rounding error;
    - prove disjointness of the core and rounded subset sums.
13. `gap-contained`.
14. `lattice-section-box` by an injective coordinate projection.
15. `index-bound`, including displayed dimension versus real rank and determinant/covolume arguments.
16. `projective-span`.

### Phase E — Projective convexity

17. Define indexed `μ`-convex position, counting multiplicity.
18. Prove `projective-duality` with the capped-simplex separation argument.
19. Prove `robust-zonotope` using slab exclusion and separation.
20. Prove `projective-convexity`:
    - obtain bounded positive representation;
    - scale by `T`;
    - delete structural exceptional/core points;
    - build the lattice tube of subset sums;
    - use the finite quotient order of `a + L` and a nearby positive multiple;
    - prove the resulting subset is nonempty before invoking shell non-divisibility.

### Phase F — Weighted density and cap lifting

21. Prove the indexed weighted-density lemma from E4 and E5:
    - finite family of witnessing half-spaces;
    - distinct perturbations preserving incidence upper bounds;
    - apply E4;
    - choose a subsequence with stabilized index set and converging `η`;
    - Hausdorff limit, volume limit, and point retention.
22. Prove cap lifting:
    - projective cone and perspective-volume ratio;
    - `K`, `K-K`, lattice span `H`;
    - E2/E5 John progression;
    - lower-rank and full-rank cases;
    - proper coefficient identification and exact functional transport.

### Phase G — Numerology and density increment

23. Define

```text
σ₁ = 1/5, σ₂ = 1/4, σ_d = (d-2)/d for d ≥ 3.
```

24. Prove `numerology`. Because `d,e ≤ D` are finite, use a finite case reduction plus monotonicity/continuity. Do not replace the compactness argument by unverified `native_decide` over real inequalities.
25. Prove the projective theorem in epsilon form:
    - contradiction family with fixed excess `ζ₀`;
    - fixed dimension and package bounds;
    - choose `ε`, `K₀`, `K`, and slowly varying `ω` in the manuscript’s order;
    - one-step preprocessing analysis: up/down/same dimension;
    - fixed excess gain for dimension changes;
    - point-retention estimate for same-dimensional blocks;
    - finitely many dimension changes;
    - eventual strict box halving contradiction.

For the slowly varying function, formalize the diagonal construction explicitly as a nondecreasing natural-valued function with the required eventual properties. Isolate it in `Asymptotic.lean` and prove a reusable diagonal-selection lemma if helpful.

### Phase H — Main theorem

26. Prove the upper bound:
    - dyadic partition of `[N]`;
    - pigeonhole a shell `[X,2X)` losing only `1 + log₂ N`;
    - instantiate the projective theorem at `d=1`, `B=[-2X,2X]`, `λ(t)=t`;
    - convert the epsilon projective estimate to `F N ≤ N^(1/5+ε)` eventually.
27. Combine with Phase A to obtain the final epsilon pair and logarithmic limit.

## 7. Known formalization hazards

1. **Zero and positivity:** divisibility by zero, shell values, and natural-to-integer casts must be ruled out explicitly.
2. **Indexed multiplicity:** projective images can coincide even though `V` is a set. Convex position and density counts must use indices, not deduplicated images.
3. **GAP dimension versus rank:** the manuscript deliberately distinguishes displayed steps from real span rank.
4. **Properness radius:** properness of `c*s*P` implies properness of `P` only after the threshold/radius argument; prove it.
5. **Coefficient maps:** `φ_P` is not a global ambient homomorphism.
6. **Subset-sum disjointness:** in one-sided filling, core and non-core subsets are disjoint; this is essential.
7. **Translations:** arbitrary translations do not preserve shell non-divisibility. Only subsets and homogeneous coefficient identifications are allowed in preprocessing.
8. **Affine hyperplanes:** use relative interior and induced `(d-1)`-measure, not ambient `d`-dimensional interior/volume.
9. **Dimension zero:** the `d=1` projective hyperplane is zero-dimensional; the manuscript’s half-space convention makes projective convexity impossible for `μ<1`.
10. **Finite quotient order:** prove positivity of the nearby multiple and nonemptiness of the subset sum.
11. **Implicit constants:** never let a constant depend on a varying set, shell functional, shell parameter, or an iteration stage when the manuscript claims uniformity.
12. **Asymptotic quantifier order:** fixed dimensions/parameters first, then threshold, then all eligible objects.
13. **Real powers/logs:** prove eventual positivity and use `Real.rpow` lemmas consistently.
14. **Dyadic pigeonhole:** formalize the exact number of shells and the loss; do not assume a shell without a finite partition proof.

## 8. Audit and acceptance checklist

Create `Nondividing/Audit.lean` and an accompanying shell command or CI step that verifies:

- `lake build` succeeds;
- repository search finds no `sorry`, `admit`, `unsafe`, `decreasing_by sorry`, or unapproved `axiom` in `Nondividing/`;
- every external axiom is located under `Nondividing/External/` and appears in the whitelist documentation;
- `#print axioms` is run for:
  - lower-bound theorem;
  - projective convexity;
  - projective theorem;
  - main upper epsilon theorem;
  - main lower epsilon theorem;
  - final logarithmic-limit theorem;
- no main theorem depends on an axiom whose type mentions `F`, `NonDividing`, `projectiveConvexity`, `projectiveTheorem`, or the final conclusion, except through the exact E1–E5 interfaces;
- all files compile from a clean checkout using the pinned toolchain.
